# 哥查德的大冒险 · GODCHARD ADVENTURE (v2.0 全动态双端版)

一款致敬《奇怪的大冒险》《正常的大冒险》的 50 关反套路赛博像素平台动作解谜游戏（高帧率流畅动作 + 零坐标纯图示攻略 + 70%–150% 按键缩放 + 章节/终章故事 CG）。

## 双端体验入口
- **网页版 / 手机离线 PWA 版**：位于 `web/` 目录（支持 GitHub Pages 在线即玩，手机浏览器可「添加到主屏幕 / 安装应用」全屏横屏离线运行）。
- **安卓原生客户端 (`.apk`)**：位于 `android/` 目录（包名 `com.godchard.adventure`，支持双向横屏沉浸全屏、线性马达震动、`SharedPreferences` 双重防丢存档与系统返回手势），已编译签名的 `.apk` 安装包可在仓库右侧 **Releases** 直接下载安装。
