# 《哥查德的大冒险 · GODCHARD ADVENTURE》网页版 / PWA 离线部署包

## 1. 本地直接运行
- 双击 `index.html` 即可在任意桌面或手机浏览器（Chrome / Edge / Safari / Firefox）中零依赖全屏游玩。
- 游戏内所有 160 项像素精灵、9 幅剧情 CG、8 幅破局图示与多乐章 8-Bit 芯片交响曲均已完整内嵌，无需联网即可运行。

## 2. 部署为在线网站 & 手机桌面离线 App (PWA)
将本目录全部文件上传至 **GitHub Pages / Vercel / Cloudflare Pages / Netlify / Nginx**（或本地运行 `python3 -m http.server 8080`）：
- **PC 浏览器**：地址栏右侧点击「安装 哥查德大冒险」即可作为独立无边框窗口运行。
- **Android 手机（Chrome / Edge）**：打开网址后点击菜单「安装应用 / 添加到主屏幕」，即可获得全屏横屏锁定的离线桌面图标体验。
- **iOS / iPadOS（Safari）**：点击「分享 -> 添加到主屏幕」即可全屏运行。

## 3. 核心操控与新特性
- **键盘操控**：`A/D` 或 `←/→` 移动，`W/Space/K/↑` 跳跃，`S/↓` 钻管道/互动，`J/Z/F` 挥剑发射剑波，`L/X/G` 投掷炸弹，`H` 打开纯图示攻略，`R` 重开本关。
- **触屏操控**：左下角人体工学方向键 + 右下角扇形动作键，支持在「设置 -> 按键大小」中按 `70%–150%` 自由调节尺寸，并支持「沉浸全屏」与「震动反馈」开关。
